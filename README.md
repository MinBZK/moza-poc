# MOZa proof of concept prototype (gearchiveerd)

U bekijkt de repo van een oude versie van het prototype van MijnOverheid Zakelijk. Deze versie werken we niet meer bij maar blijft bewaard ter referentie.

De nieuwe versie staat in [de repo `moza-portaal`](https://github.com/MinBZK/moza-portaal/). Dit nieuwe prototype maakt gebruik van React en Next.js i.p.v. statische HTML/CSS/JavaScript. Zo kunnen we het prototype beter aansluiten op echte diensten en gegevens.
